# International Marketing Intel

一个用于会前研究国际营销、广告、品牌和行为科学专家的 Codex Skill。

它会把公开信息整理成一份可快速阅读的会前简报，重点包括：

- 近 90 天的本人动态与行业信号
- 自述与外界评价的差异
- 营销方法论、品牌/增长判断和个人表达风格
- 中英文 Talking Points
- 信源、置信度与搜索盲区

## 安装

将此目录复制到：

\`\`\`
~/.codex/skills/international-marketing-intel
\`\`\`

下一轮对话即可使用；也可以显式调用 \`$international-marketing-intel\`。

## 示例

\`\`\`
研究一个国际营销高手，重点看他的品牌增长方法，并准备我可以问的问题。
\`\`\`

\`\`\`
用 international-marketing-intel 研究 Rory Sutherland，会议目的是了解行为营销和品牌增长。
\`\`\`

## 说明

默认输出本地 Markdown。若当前环境提供飞书文档能力并且用户没有要求仅在聊天中预览，则可继续落档飞书；否则不会因为缺少飞书依赖而阻塞。
